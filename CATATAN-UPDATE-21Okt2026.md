# Update 21 Okt 2026 (tanpa migrasi, tanpa artisan)
Timpa file sesuai foldernya, lalu refresh browser (Ctrl+F5).

1. Buku Besar: filter cut-off tanggal (Bulan Ini / Tahun Ini / Semua / dari-sampai). Transaksi sebelum tanggal "dari" menjadi baris Saldo Awal; ada total mutasi & saldo akhir per tanggal cut-off.
2. Riwayat Penjualan: keterangan cara baca kolom di bawah judul, header kolom (Qty, Harga Jual, Diskon, HPP, PPN, Subtotal) tampil di dalam nota. Diskon kosong tampil 0. Kolom HPP baru (merah = 0 / belum ada pembelian).
3. Laba Rugi: HPP dipecah Persediaan Awal + Pembelian (+/- Penyesuaian lain) = Barang Tersedia - Persediaan Akhir = Total HPP.
4. Peringatan "barang tanpa Harga Modal": "... dan N lainnya" bisa diklik -> daftar lengkap + pencarian. Batas 50 barang dinaikkan jadi 3.000.
